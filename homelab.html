Homelab

Home Lab & Virtualization

My home lab is built around Proxmox and runs multiple virtual machines that support both my day-to-day computing needs and ongoing learning. I use the environment to run and maintain personal services, manage systems, and troubleshoot real-world issues, while also using it as a safe environment to practice system administration, networking, virtualization, and other technologies relevant to my professional work in IT.

Proxmox Virtual Environment

Proxmox is the core of my environment, hosting and managing all of my virtual machines and containers on my network.

TrueNAS Storage

TrueNAS provides centralized storage for my environment, handling file sharing, backups, and data organization.

Windows Virtual Machines

My Windows VMs are used for both personal use and practicing system administration and troubleshooting Windows-related issues. They also provide a controlled environment for testing configurations, software, policies, and system changes before deploying them to other devices.

Linux Server VMs

My Linux VMs (Mint, Ubuntu, and Debian) are used for server-based workloads, hosting local network services, software development, and troubleshooting Linux environments. I also use them for AI and LLM experimentation, including running and testing local models and related services.

ADS-B / FR24 Server

A dedicated Ubuntu server collects and shares real-time aircraft data with platforms like FlightAware and Flightradar24.

Docker & Network Services

Docker is used to run lightweight services such as ad blocking and 3D printing server on my home network.
